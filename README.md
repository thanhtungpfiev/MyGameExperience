# 🎮 MyGameExperience

Vault ghi chú cá nhân về trải nghiệm chơi game, viết bằng [Obsidian](https://obsidian.md). Hiện tập trung vào **Stardew Valley 1.6.15** (bản Việt hóa).

## 📂 Nội dung

### 🌱 Stardew Valley
Mở `StardewValley/00 Home.md` làm điểm bắt đầu — đây là mục lục trung tâm dẫn tới:

| Note | Nội dung |
|------|----------|
| **00 Home** | Trang chủ: trạng thái save, việc ưu tiên, link nhanh |
| **Mods** | 26 mod đang dùng — công dụng, phím tắt, cấu hình GMCM, thứ tự cài |
| **Daily** | Nhật ký theo ngày + lịch trình & việc cần làm theo mùa |
| **Mẹo** | Bản đồ Anh–Việt, kiếm tiền, trồng trọt, kết bạn, khai thác, câu cá |

## 🛠️ Cách dùng

- Mở thư mục này như một vault trong **Obsidian** để xem đầy đủ liên kết `[[wikilink]]`, ảnh nhúng và bảng.
- Ảnh minh họa nằm trong `StardewValley/assets/`.
